# JavaScript Testing Practice

A collection of utility functions built to practice Test-Driven Development (TDD) and unit testing using Jest. Built using the [Vanilla JS Template](https://github.com/cmatsagka/vanilla-js-template).

🚀 **Included Modules & Features**

1. **Analyze Array (`analyzeArray`)**: Takes an array of numbers and returns an object detailing the average, minimum, maximum, and total length.
2. **Calculator (`calculator`)**: An object containing basic arithmetic functions (add, subtract, divide, multiply).
3. **Capitalize (`capitalize`)**: Takes a string and returns it with the first character capitalized.
4. **Caesar Cipher (`caesarCipher`)**: Shifts characters in a string by a specified factor while preserving case and wrapping from 'z' to 'a'.
5. **Reverse String (`reverseString`)**: Takes a string and returns it reversed.

🛠️ **Installation & Testing**

This project uses Babel to support modern ES6 modules and Jest for rigorous unit testing of edge cases.

Clone the repo:

```bash
git clone git@github.com:cmatsagka/javascript-testing-practice.git
```

Install dependencies:

```bash
npm install
```

Run tests:

```bash
npm test
```
